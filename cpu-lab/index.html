Quick coding guide

LDA N copies RAM[N] into ACC. STA N copies ACC into RAM[N]. Use a label or a four-bit address for N.

DAT 0111 reserves a cell containing exactly 0111. DAT is an assembler directive.

Addressed commands use two cells: an opcode, then its address. INP, OUT and HLT each use one cell.

More cores help with parallel work.

The benefit depends on which addresses the program uses. Try the same sequence with the cache off, 2 slots and 4 slots.
About this cache model
Each slot holds a copy of one 4-bit data value. The @ symbol marks a memory address; every address and data value is displayed as four binary digits. A full cache replaces the least recently used entry. Occupied slots are ordered from least to most recently used, reading left to right and then top to bottom. Real caches usually transfer blocks of memory and use more complex arrangements. The timings here are teaching examples, not measurements of a real CPU.

The cycle dial
The clock has three labelled dots for Fetch, Decode and Execute. The current stage is highlighted. In the simulator it follows the current instruction; in Explore it previews the repeating sequence. These stages can each take multiple hardware clock cycles.
Following the result
The ALU places a calculation result in ACC. When STA executes, ACC is copied to MDR; the CU sends WRITE and the data bus carries the word to RAM at the address held in MAR. CIR and IR name the same instruction register in this app. The CU decodes the instruction in CIR and sends control signals to select the ALU operation.
What this model simplifies
  • One core and 16 shared RAM cells, each holding four bits. Data ranges from 0000 to 1111. Arithmetic outside this range stops with an explanation.
  • CIR holds a four-bit opcode. Addressed commands use the next cell for a four-bit address, fetched during Execute. INP, OUT and HLT each use one cell. This is an illustrative instruction encoding.
  • PC points to the next program word in this model and wraps from 1111 to 0000. A branch replaces this address.
  • DAT is an assembler directive, not a CPU instruction. RAM holds both instructions and data. Its Meaning column shows an instruction mnemonic or denary value as a reading aid. Every copy preserves the four bits exactly.
  • Animation speed is for learning. Teaching steps are not hardware clock cycles. Cache and multiple cores are explored separately.
  • Cache stores copies of memory contents. Registers hold the immediate working state. The single main RAM view is outside the CPU.
For a classroom discussion
Ask students to predict ACC, PC and output before running. Then ask them to name the register, bus and control signal responsible for each transfer. Use single-step mode when introducing a new instruction.
